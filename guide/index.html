이 페이지는 검색과 비로그인 열람을 위한 요약 가이드입니다. 실제 설정 버튼과 화면별 복구 방법은 와니온의 대화형 가이드에서 제공합니다.

기능 기준: 2026-08-26

일반 사용자

  1. Google 계정으로 로그인합니다.
  2. Battle.net을 연결하고 사용할 대표 캐릭터를 선택합니다.
  3. 대표 캐릭터 프로필에서 계정 수집 현황과 최근 여섯 시즌 레이드 기록을 확인합니다.
  4. 파티 목록은 간단한 보드·달력 전환과 필요할 때만 여는 상세 필터로 탐색합니다.
  5. 파티 상세에서 일정, 정원, 신청 방식을 확인하고 캐릭터와 전문화를 선택합니다.
  6. 내 신청에서 확정·대기·벤치 상태와 변경 요청 결과를 확인합니다.

길드·정공·연합 운영진

  1. 조직 등록과 운영 권한을 확인합니다.
  2. 가입 회원과 미가입 구성원을 캐릭터명·서버 검색으로 명단에 연결합니다. 미가입 구성원이 가입하면 검증된 동일 캐릭터 기준으로 기존 기록을 승계합니다.
  3. 미가입 캐릭터의 직업·직업색은 Blizzard 공개 프로필에서 저장하며 기존 명단도 자동 보정합니다.
  4. 정공 운영자는 음험시트에서 아이템 레벨 소수점, 티어 부위, 장신구와 주간 쐐기 횟수를 확인합니다.
  5. Discord 탭에서 기존 포럼을 선택하거나 새 포럼을 만들고 게시 범위와 일정 분류를 지정합니다.
  6. 정공은 WCL의 공개 길드·팀 리포트 주소를 연결해 현 시즌 레이드 인사이트를 구성합니다.

문제가 생기면

INTERNAL 같은 원문 오류를 반복하지 말고, 화면에 표시된 복구 행동을 먼저 실행합니다. 계속 실패하면 발생 화면, 시각, 조직·파티명과 추적 ID를 함께 전달합니다. 비밀번호나 연결 토큰은 보내지 않습니다.
