# Wani Guide State Illustration Set

Transparent state illustrations generated for contextual guidance in WANION.

1. `wani-guide-stuck.png` — blocked or uncertain next step
2. `wani-guide-battlenet.png` — Battle.net connection
3. `wani-guide-discord.png` — Discord connection
4. `wani-guide-no-parties.png` — no matching parties
5. `wani-guide-no-applicants.png` — no applicants
6. `wani-guide-waiting.png` — awaiting approval
7. `wani-guide-success.png` — setup or submission completed
8. `wani-guide-recovery.png` — recoverable connection or data error
9. `wani-guide-operations.png` — raid operations guidance
10. `wani-guide-help.png` — detailed help and guide

All illustrations use the canonical Wani character direction and must retain exactly two front limbs, two hind legs, and one tail.
