RAID LEADER

모집 전 합의가
진행 중 갈등을 줄입니다

좋은 운영은 많은 기능을 쓰는 것이 아니라 누가 무엇을 언제 결정하는지 참가자가 알 수 있게 만드는 일입니다.

작성·검수: 와니온 운영팀수정: 2026년 9월 15일

1. 개설 전

  • 공략 날짜와 종료 시각, 난이도, 목표 구간을 확정합니다.
  • 편안한·집중·확고 중 실제 진행 성향을 선택합니다.
  • 귀속, 선수·손님 구성, 준비물과 음성 채널 사용 여부를 적습니다.
  • 개설자가 진행하지 않으면 실제 공대장을 지정합니다.

2. 권한 구분

실제 공대장은 파티 운영 권한을 함께 갖습니다. 구인 담당이나 배치 담당이 따로 필요하면 파티 관리자로 추가합니다. 관리자는 해당 파티만 수정할 수 있어야 하며 플랫폼 전체 권한과 혼동해서는 안 됩니다.

3. 모집과 확정

지원자의 캐릭터, 역할, 전문화, 참여 조건을 확인하고 상태를 확정·대기·벤치로 구분합니다. 지인이나 길드원도 공지한 기준과 다르게 처리하지 않습니다. 캐릭터 교체가 있으면 동일인 기록을 유지해 중복 공대원이 생기지 않도록 합니다.

4. 당일 운영

시작 전 결원과 역할 스왑을 확인하고 파티 배치를 공유합니다. 피드백은 행동과 공략 기준에 한정하며 인격을 평가하지 않습니다. 일정이나 목표가 달라졌다면 공지 없이 강행하지 않습니다.

5. 종료 후

종료 상태를 확정하고 필요하면 로그와 공지를 연결합니다. 참가자 평가는 보복 수단이 아니며 실제 참여자만 제출해야 합니다. 개인정보나 개인 로그 스크린샷을 외부에 공유할 때는 식별 정보를 가립니다.
