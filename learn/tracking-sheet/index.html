트래킹 시트는 활동 중인 공대원의 준비 상태를 한눈에 보는 운영 도구입니다. 대기자와 벤치를 섞거나 역할별 로그 기준을 통일하지 않으면 평균이 왜곡됩니다.

안내 주체: 와니온 운영팀문서 수정: 2026년 10월 6일

집계 대상

평균은 정규 상태의 로스터 중 앞에서 최대 20명을 포함합니다. 분모는 고정 20이 아니라 실제 포함된 인원수이며, 대기·벤치·예비 인원은 제외합니다. 현재 계산에서는 포함된 사람의 값이 없거나 숫자로 읽을 수 없으면 합계에 0으로 반영하고 분모에서는 빼지 않습니다. 따라서 누락이 있는 평균은 기록이 확인된 사람만의 평균보다 낮아질 수 있습니다. 정규 인원이 없으면 평균은 표시하지 않습니다.

누락값이 있는 가상 예시

정규 인원 3명의 영웅 점수가 90, 60, 기록 없음이면 현재 표시 평균은 (90 + 60 + 0) ÷ 3 = 50.0입니다. 기록이 확인된 두 사람만 계산한 75.0과 다릅니다. 이는 계산 설명이며 실제 공대 성과가 아닙니다. 개별 기록 없음은 실력이 0점이라는 뜻이 아닙니다.

평균 장착 레벨은 소수 둘째 자리, 영웅·신화 로그 평균은 소수 첫째 자리로 표시합니다.

트래킹 시트는 등록된 기본 역할로 조회한 영웅·신화 기록을 표시합니다. 역할 스왑이 활성화되어 있고 다른 보조 역할이 설정되어 있으면 그 역할의 조회 기록을 별도 줄로 표시합니다. 요약 평균은 기본 역할 점수를 사용하며 보조 역할 점수를 더하거나 보스별로 자동 선택하지 않습니다. 실제 전투에서 맡은 역할은 WCL 원본 보고서에서 따로 확인하세요.

점수와 색상

표시값은 베스트 퍼포먼스 점수를 소수점 한 자리 형태로 보여줍니다. 색상은 Warcraft Logs의 구간 표현을 따라 읽기 편하게 만들지만, 색상만으로 출석·공략 수행·협업 능력을 평가하지 않습니다. 영웅과 신화 평균에도 같은 색상 함수를 사용해야 화면마다 의미가 달라지지 않습니다.

갱신

외부 API 조회와 저장된 캐시를 거쳐 표시하므로 지금 화면이 게임의 현재 상태와 항상 같지는 않습니다. 조회 실패 시 마지막 성공 데이터가 남아 있다면 해당 값과 갱신 시각·오류 표시를 함께 확인하세요. 마지막 성공값 보존과 위에서 설명한 요약 평균의 누락값 0 반영은 서로 다른 처리입니다. 새 로그가 공개되어도 WCL 처리와 캐시 주기 때문에 즉시 반영되지 않을 수 있습니다.

비공개 또는 업로드되지 않은 전투는 집계할 수 없습니다. 기록 없음은 낮은 점수가 아닙니다.
