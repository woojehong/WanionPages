RAID OPERATIONS 04

로그 숫자는 결론이 아니라
공략 흐름의 기록입니다

Warcraft Logs 공개 리포트는 공대의 진행을 되돌아보는 근거가 될 수 있지만, 업로드 누락과 비공개 설정까지 실력으로 해석하면 안 됩니다. 데이터가 보여주는 범위와 보여주지 않는 범위를 함께 표시해야 합니다.

먼저 같은 범위인지 확인합니다

공격대·난이도·대상 조직·조회 시점을 맞춰 비교합니다. 공개되지 않았거나 업로드되지 않은 전투는 포함할 수 없습니다. 데이터 없음은 전투 실력 0점이 아닙니다.

BEST RDPS의 실제 계산 범위

현재 와니온은 WCL에서 받은 전투별 랭킹의 탱커·힐러·딜러 참가자 수치(amount)를 합산하고 소수 첫째 자리로 반올림합니다. 양수인 전투별 합계 중 보스·난이도별 최댓값을 구하며, 난이도 요약에는 해당 난이도 보스들의 최댓값을 표시합니다. 전체 평균이나 개인 최고 기록의 합계가 아닙니다.

전투별 값 = 탱커·힐러·딜러 참가자 수치의 합계
난이도 BEST RDPS = 해당 난이도의 유효 전투별 값 중 최댓값

가상 예시: 전투 A의 합계가 1,000,000, 전투 B가 1,200,000이면 BEST는 1,200,000입니다. 평균 1,100,000이 아닙니다. 이 숫자는 계산 설명용이며 실제 공대 기록이 아닙니다. 누락된 랭킹은 0의 실력으로 평가하지 않습니다.

이 합산은 WCL이 제공한 참가자 수치를 사용하는 방식입니다. 와니온이 원시 피해량을 전투 시간으로 나누어 새로 산출하는 값은 아닙니다. 외부 지표 정의·전투 길이·보스 구조가 다른 기록을 이 숫자만으로 비교하지 마세요.

공략 시간과 풀 수는 다릅니다

풀 수는 집계 대상 전투의 시도 횟수입니다. 처치 전후의 전투나 업로드 범위 차이를 고려해야 합니다. 전투 시간의 합과 첫 전투부터 마지막 전투까지의 시간은 휴식 포함 여부가 다릅니다. 화면의 시간 항목을 서로 바꾸어 읽지 마세요.

기록이 예상과 다를 때

  1. WCL 원본에서 공개 리포트와 난이도를 확인합니다.
  2. 와니온의 대상 조직·공격대·최근 갱신 표시를 확인합니다.
  3. 방금 올린 기록이라면 곧바로 누락이나 오류로 단정하지 않습니다.
  4. 차이가 계속되면 리포트 링크·보스·난이도·확인 시각·화면 값을 문의에 남깁니다. 비공개 로그를 공개로 바꾸도록 다른 사람에게 강요하지 않습니다.

처치 주차는 화면의 기준일을 함께 읽어야 합니다. 이 문서에는 검증하지 않은 주차 산식을 추가하지 않았습니다. 로그는 출석 태도·의사소통·개인 사정까지 설명하지 못합니다.
