스냅샷
현재 구성 상태를 확인용으로 저장해 웹의 명단과 비교합니다.

권한과 제한

공격대 초대와 그룹 이동은 게임 내 권한, 전투 상태와 Blizzard UI 제한을 받습니다. 애드온은 보호된 동작을 임의로 실행하거나 외부 서버에서 게임 클라이언트를 조작하지 않습니다. 버튼이 비활성화되면 공격대장 또는 지원 권한과 전투 상태를 먼저 확인합니다.

문제 해결

  1. 애드온 목록에서 와니온 어시스트가 활성화되어 있는지 확인합니다.
  2. 게임 업데이트 뒤 구버전 경고가 나타나면 최신 배포본을 확인합니다.
  3. 복사한 코드의 앞뒤가 잘리지 않았는지 확인합니다.
  4. UI 오류가 반복되면 오류 메시지와 애드온 버전을 함께 제보합니다.

와니온 어시스트는 Blizzard Entertainment의 공식 애드온이 아닙니다. 초대·그룹 이동은 게임 내 권한과 보호된 동작의 제한을 받으며, 제한되는 상황에서는 실행되지 않을 수 있습니다.

처음 가져올 때의 확인 순서

  1. 게임을 종료하고 설치 폴더와 애드온 목록을 확인합니다.
  2. 웹 운영 데스크에서 적용할 일정과 저장된 명단·배치를 확인한 뒤 코드를 복사합니다.
  3. 게임에서 어시스트를 열고 코드 전체를 붙여넣습니다.
  4. 적용 전 대상 캐릭터·서버·그룹이 기대한 구성인지 읽습니다. 다른 일정 코드라면 적용하지 않습니다.
  5. 게임 내 권한과 전투 상태를 확인하고 필요한 버튼을 직접 눌러 실행합니다.
  6. 적용 후 실제 공격대 명단과 웹 명단을 대조합니다. 초대 실패 인원을 이미 참여한 인원으로 세지 않습니다.

코드가 잘렸다면 같은 일정에서 다시 복사하되 실제 초대를 반복 실행하기 전 게임 명단부터 확인합니다. 오류 제보에는 애드온 버전·직전 행동·오류 문구를 적고 비공개 명단 전체나 계정 인증정보를 보내지 않습니다. 이 절차는 실제 게임 실행 시험 결과가 아닙니다.
