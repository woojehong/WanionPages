와니온 어시스트는 웹에서 만든 초대 명단과 파티 배치를 게임 안에서 적용하도록 돕습니다. 게임 정책상 자동화할 수 없는 동작은 이용자의 클릭이 필요합니다.

작성·검수: 와니온 운영팀수정: 2026년 9월 15일

주요 기능

캘린더 패널
기본 캘린더 옆 와니온 버튼으로 열고 닫습니다. 긴 명령어 대신 /wan c로도 열 수 있습니다.
순차 초대
웹에서 복사한 초대 코드를 붙여 넣고 확인된 대상부터 초대합니다. 접속하지 않은 인원은 다시 시도할 수 있습니다.
파티 배치
파티 운영 데스크에서 저장한 배치 코드를 가져와 그룹 구성을 적용합니다.
스냅샷
현재 구성 상태를 확인용으로 저장해 웹의 명단과 비교합니다.

권한과 제한

공격대 초대와 그룹 이동은 게임 내 권한, 전투 상태와 Blizzard UI 제한을 받습니다. 애드온은 보호된 동작을 임의로 실행하거나 외부 서버에서 게임 클라이언트를 조작하지 않습니다. 버튼이 비활성화되면 공격대장 또는 지원 권한과 전투 상태를 먼저 확인합니다.

문제 해결

  1. 애드온 목록에서 와니온 어시스트가 활성화되어 있는지 확인합니다.
  2. 게임 업데이트 뒤 구버전 경고가 나타나면 최신 배포본을 확인합니다.
  3. 복사한 코드의 앞뒤가 잘리지 않았는지 확인합니다.
  4. UI 오류가 반복되면 오류 메시지와 애드온 버전을 함께 제보합니다.

와니온 어시스트는 Blizzard Entertainment의 공식 애드온이 아닙니다. 게임 이용약관과 애드온 정책이 허용하는 범위에서 동작합니다.
