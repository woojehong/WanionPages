Battle.net 목록 조회가 거부될 때

  1. 연결한 Battle.net 계정이 해당 캐릭터를 보유하는지 확인합니다.
  2. Battle.net 계정 연결 권한이 취소되지 않았는지 확인하고 필요하면 다시 연결합니다.
  3. 캐릭터 이름·서버·지역이 검색 결과와 일치하는지 확인합니다.
  4. Blizzard 캐릭터 프로필을 한 번 갱신한 뒤 전역 캐시 주기를 기다립니다.

미가입 사용자를 검색으로 추가할 때는 공개 캐릭터 정보만 사용합니다. 가입자가 나중에 같은 캐릭터를 연결하면 캐릭터의 지역·서버·이름을 정규화해 기존 미가입 기록과 병합해야 하며, 이름만 비슷한 다른 사람을 자동 병합해서는 안 됩니다.

아이템 레벨이 오래된 경우

게임 내 장비 변경이 즉시 Blizzard 프로필에 반영된다는 보장은 없습니다. 와니온은 활성 캐릭터를 주기적으로 갱신하되 외부 API 호출 제한을 피하기 위해 캐시를 사용합니다. 공대장의 수동 갱신은 최신 상태가 꼭 필요한 때를 위한 기능이며 연속 호출은 제한될 수 있습니다.

WCL 기록이 비어 있을 때

  • 보고서가 공개인지 확인합니다.
  • 현재 시즌·공격대·영웅 또는 신화 난이도가 맞는지 확인합니다.
  • 팀 또는 길드 식별자가 실제 보고서 소유 범위와 일치하는지 확인합니다.
  • 목록 첫 페이지만 읽지 않고 전체 공개 보고서를 확인했는지 점검합니다.
  • 업로드 직후라면 WCL 처리와 와니온 캐시 갱신을 기다립니다.

그래도 해결되지 않으면

캐릭터명, 서버, 발생 시각, 사용 환경, 기대한 값과 실제 값을 함께 제보하세요. 인증 토큰이나 계정 비밀번호는 보내지 않습니다.

외부 서비스 장애나 비공개 설정은 와니온이 우회할 수 없습니다. 실패 시 마지막 성공값을 유지하는 것이 정상 동작입니다.
